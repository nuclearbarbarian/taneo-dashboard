About This Dashboard

What it does

This dashboard tracks every nuclear power project in Texas, the permits each one needs from federal and state agencies, and the milestone-level progress of each permit. The unit of analysis is the project — but every permit and every step within it is visible.

Click any project name to see its full permit timeline, organized by agency. Cross-project comparisons live on the Permit Matrix. The Regulatory Guide documents what each Texas state permit requires, who issues it, and how long it takes.

What it does not do

This is a beta. Data is curated manually from public sources, not pulled from live agency feeds. Some milestone dates — particularly NRC review schedules and state permit applications that have not been filed — carry the flags below to mark uncertainty:

  • [ESTIMATE] developer-stated date, not confirmed by agency record
  • [GAP] data not publicly available; TANEO/developer input needed
  • [PROJECTED] pre-application stage; permits anticipated, not yet filed

The aim is to show what is known, mark what is not, and never confuse the two.

Sources. NRC docket data via nrc.gov project pages; state permit requirements via tceq.texas.gov, dshs.texas.gov, and ercot.com; TANDF program detail via gov.texas.gov/taneo.
